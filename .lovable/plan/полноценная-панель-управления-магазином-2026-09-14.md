# Полноценная панель управления магазином

Сейчас на странице `/admin` есть простой список заявок и короткий список товаров. Сделаем из этого рабочую панель с двумя разделами: «Заказы» и «Товары», с загрузкой фотографий прямо с компьютера.

## Заказы

- Отдельная вкладка со списком всех заказов, самые новые сверху.
- Наверху четыре плитки: новых, подтверждённых, доставленных, сумма за последние 30 дней.
- Фильтр по статусу (все / новые / подтверждённые / доставленные / отменённые) и поиск по имени, телефону или адресу.
- Каждый заказ можно раскрыть: состав корзины позициями с ценами, стоимость доставки, итог, дата и интервал доставки, комментарий покупателя.
- Статус меняется одним нажатием на цветной значок; телефон — ссылка для звонка, есть кнопка «Скопировать адрес».
- Ненужный (например тестовый) заказ можно удалить с подтверждением.

## Товары

- Плиточный список всех букетов с фото, ценой, видом и отметкой «скрыт».
- Поиск по названию, фильтр по виду, переключатель «показывать на сайте» прямо в плитке.
- Полная карточка редактирования во всплывающем окне: название, адрес-ссылка (подставляется автоматически из названия), вид, оттенок, описание, цена, число стеблей, высота, стойкость, порядок вывода, видимость.
- Копирование позиции («Дублировать») и удаление с подтверждением.

## Фотографии с компьютера

- Заводим хранилище для картинок товаров (общедоступное на чтение, загрузка — только для администратора).
- В карточке товара — область загрузки: выбрать файл или перетащить его. Сразу видно превью, можно заменить или убрать фото.
- Ограничения: JPG, PNG, WebP, до 5 МБ; при превышении понятное сообщение.
- Загруженное фото сразу показывается на сайте вместо встроенных иллюстраций.

## Технические детали

- Storage-бакет `product-images` (public read), RLS-политики на `storage.objects`: чтение всем, запись/удаление — при `has_role(auth.uid(),'admin')`.
- Загрузка из браузера через `supabase.storage.from('product-images').upload()`, в `products.image_url` пишется public URL; `productImage()` в `src/lib/shop.ts` уже поддерживает http-ссылки.
- `src/routes/admin.tsx` разбивается на компоненты в `src/components/admin/`: `OrdersPanel`, `OrderRow`, `ProductsPanel`, `ProductForm`, `ImageUploader`; проверка сессии и роли admin остаётся как есть.
- Данные — через React Query с инвалидацией ключей `orders` / `products`, стиль панели — существующие токены Pastel atelier, включая тёмную тему.
- Схема таблиц `products` и `orders` не меняется.
