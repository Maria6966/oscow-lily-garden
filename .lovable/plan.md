# Чат-помощник в правом нижнем углу

## Что увидит покупатель

1. Круглая кнопка с иконкой чата в правом нижнем углу на всех страницах сайта (переключатель темы остаётся слева).
2. По нажатию открывается панель чата. Первый шаг — короткая форма: имя, телефон и галочка согласия с политикой конфиденциальности. Без согласия кнопка «Начать чат» неактивна.
3. После этого открывается диалог с помощником мастерской «Лилия». Он:
   - знает весь актуальный ассортимент (название, вид, оттенок, цена, количество стеблей, высота, стойкость) и подбирает букет под повод, бюджет и цвет;
   - помогает собрать составной букет из нескольких позиций, считает стоимость, доставку (500 ₽ по МКАД, бесплатно от 5 000 ₽) и итог;
   - показывает собранный букет отдельной карточкой со составом и суммой;
   - когда покупатель согласен — спрашивает адрес, дату и удобное время и оформляет заявку, она сразу появляется в разделе «Заказы» панели;
   - если вопрос сложный или покупатель просит человека — передаёт разговор живому оператору: в чате появляется пометка «Флорист скоро подключится», а в панели создаётся тикет.
4. Разговор живёт в текущей вкладке: при возврате на сайт начинается новый чат (все прошлые сохраняются в панели).
5. Когда сотрудник отвечает из панели, ответ появляется в том же окне чата у покупателя (окно проверяет новые сообщения каждые несколько секунд).

## Что появится в админке

Новая вкладка «Чаты» рядом с «Заказами» и «Товарами»:

- список всех разговоров (даже без тикета) с именем, телефоном, временем, первым вопросом и метками «Нужен оператор» / «Оформлена заявка»;
- фильтр: все / требуют оператора / с заявкой, и поиск по имени и телефону;
- открытый разговор показывает всю переписку; сотрудник пишет ответ прямо в этом окне — покупатель видит его в чате на сайте;
- отметка «Вопрос решён», чтобы снять пометку о необходимости оператора;
- если из чата оформлена заявка, у неё есть ссылка на заказ; заказы из чата помечены источником «Чат».

## Технические детали

- Таблицы: `chat_sessions` (имя, телефон, согласие, токен сессии, флаг `needs_operator`, `order_id`, время) и `chat_messages` (роль user/assistant/operator/system, текст, время). RLS: чтение/обновление только для `has_role(auth.uid(),'admin')`; анонимного доступа к таблицам нет — покупатель работает через серверные функции, которые проверяют токен сессии из `sessionStorage`. GRANT для `authenticated` и `service_role` в той же миграции.
- Серверные функции (`src/lib/chat.functions.ts`, `createServerFn`): `startChatSession`, `sendChatMessage`, `pollChatMessages`. Внутри — сервисный клиент, загружаемый в теле обработчика после проверки токена.
- ИИ: Lovable AI Gateway, модель `openai/gpt-6-astra` через Responses API со стримингом, ключ только на сервере. Системная подсказка на русском, с ассортиментом из `products` и правилами доставки. Инструменты: `search_products`, `quote_bouquet` (расчёт по позициям), `create_order` (вставка в `orders` с `source='chat'`), `request_operator` (тикет). Ошибки шлюза (нет кредитов, лимит) показываются в чате понятным текстом с предложением позвать оператора.
- UI: AI Elements (`conversation`, `message`, `prompt-input`, `shimmer`, `tool`) устанавливаются из реестра, оформление — токены Pastel atelier, светлая и тёмная темы. Кнопка и панель в `src/components/chat/`, подключение в `src/routes/__root.tsx`, скрыто на `/admin` и `/auth`.
- Админка: `src/components/admin/ChatsPanel.tsx` + серверная функция ответа оператора; в `orders` добавляется столбец `source` (по умолчанию `site`).
- Иконка помощника — сгенерированная в стиле магазина, без generic-звёздочек.
